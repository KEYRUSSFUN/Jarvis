# Jarvis

Командный проект. Репозиторий приватный: доступ есть только у участников команды.

## Как работаем

1. Склонировать репозиторий:

   ```
   git clone https://github.com/KEYRUSSFUN/Jarvis.git
   cd Jarvis
   ```

2. Создать свою ветку (имя — свой логин на GitHub) и работать только в ней:

   ```
   git checkout -b <логин>
   git push -u origin <логин>
   ```

3. Перед работой подтянуть свежие изменения из `main`:

   ```
   git pull origin main
   ```

4. Фиксировать изменения и отправлять их в свою ветку:

   ```
   git add <файлы>
   git commit -m "Что сделано"
   git push
   ```

5. Когда версия рабочая — открыть Pull Request из своей ветки в `main`.
   После проверки его вливают в основную ветку.

## Ветки

# Jarvis: Архитектура и план разработки

Реализация полноценного голосового управления компьютером. В основе проекта лежит модульная агентная архитектура на Python с упором на локальные модели для обеспечения приватности, скорости и независимости от интернета.

## 🧠 Концепция и архитектура

В основе Jarvis лежит агентный подход: вы голосом ставите задачу, LLM (языковая модель) интерпретирует её, разбивает на шаги и вызывает соответствующие инструменты (Tools) для взаимодействия с операционной системой.

**Базовый цикл обработки команды:**
1. **Аудио-поток**: Микрофон постоянно слушает и передаёт звук в модуль VAD (Voice Activity Detection), который определяет наличие речи и отсекает тишину.
2. **Распознавание речи (STT)**: Обнаруженный фрагмент речи отправляется в модель `faster-whisper` для перевода в текст.
3. **Мозг (LLM)**: Текст команды и системный промпт (с описанием доступных инструментов) отправляются в локальную LLM (например, `Llama 3.1` через `Ollama`). Модель возвращает JSON-план с вызовом нужных функций.
4. **Слой действий (Tools)**: Python-интерпретатор выполняет вызванные функции: открывает приложения, эмулирует нажатия клавиш, работает с файлами.
5. **Обратная связь (TTS)**: Результат выполнения команды или ответ ассистента синтезируется в речь и воспроизводится через динамики.

## 🛠️ Стек технологий

| Компонент | Технология | Обоснование |
| :--- | :--- | :--- |
| **Язык** | **Python 3.11+** | Оптимальный выбор для ИИ-проектов, огромное количество библиотек. |
| **Распознавание речи (STT)** | **`faster-whisper`** | Локальная модель, работающая на GPU/CPU с низкой задержкой и высокой точностью. |
| **VAD (детекция речи)** | **`Silero VAD`** | Легковесная и точная модель для определения начала и конца речи, экономит ресурсы. |
| **Мозг (LLM)** | **`Ollama` + `Llama 3.1`** | Полностью локальный запуск, отличная поддержка вызова функций (function calling) и приватность данных. |
| **Синтез речи (TTS)** | **`edge-tts`** или **`Piper`** | `edge-tts` даёт высокое качество нейроголоса (как в JARVIS) при наличии интернета. `Piper` — полностью офлайн-альтернатива. |
| **Автоматизация ОС** | **`PyAutoGUI`**, **`subprocess`**, **`pywinauto`** | `PyAutoGUI` управляет мышью и клавиатурой. `subprocess` запускает системные команды. `pywinauto` помогает работать с окнами и GUI-элементами Windows. |
| **Фреймворк для агентов** | **`LangChain` / `LangGraph`** | Упрощает создание агентов со сложной логикой и управление инструментами (tools). |

## 📋 Подробный план реализации

Работу над проектом предлагается разбить на следующие этапы для итеративной разработки:

### Этап 1: Инициализация и аудио-конвейер
- **Настройка проекта**: Создать структуру репозитория, настроить виртуальное окружение и `requirements.txt`.
- **Захват аудио**: Реализовать постоянную запись с микрофона с помощью `sounddevice` или `PyAudio`.
- **Детекция речи (VAD)**: Интегрировать `Silero VAD`, чтобы система реагировала только на речь, а не на фоновый шум.
- **Распознавание (STT)**: Подключить `faster-whisper` для перевода аудио в текст. 
- **Цель этапа**: получать чистый текст команды.

### Этап 2: Ядро на LLM и "Мозг"
- **Установка LLM**: Установить `Ollama` и загрузить модель `Llama 3.1` (например, 8B).
- **Системный промпт**: Написать детальный промпт, описывающий роль ассистента, правила безопасности и, главное, список доступных инструментов с их описанием.
- **Обработка запросов**: Научиться отправлять текст в `Ollama` и получать структурированный JSON-ответ, содержащий команду для выполнения.

### Этап 3: Слой действий (Tools)
Реализовать базовый набор Python-функций (инструментов), которые будет вызывать LLM:
- **Управление приложениями**: Запуск и закрытие программ (`subprocess`).
- **Эмуляция ввода**: Нажатия клавиш, клики мышью, набор текста (`PyAutoGUI`).
- **Работа с файлами**: Создание, перемещение, удаление файлов и папок (`os`, `shutil`).
- **Системная информация**: Получение данных о заряде батареи, CPU, RAM (`psutil`).

### Этап 4: Обратная связь (TTS)
- **Синтез речи**: Подключить `edge-tts` для озвучивания ответов ассистента.
- **Воспроизведение**: Настроить вывод аудио. Важно добавить обработку прерывания (interruption), чтобы ассистент замолкал, когда вы начинаете говорить.

### Этап 5: Интеграция и повышение надежности
- **Сборка пайплайна**: Связать все модули (VAD → STT → LLM → Tools → TTS) в единый цикл.
- **Безопасность**: Добавить слой безопасности (safety guardrails), который будет блокировать потенциально опасные команды (например, удаление системных файлов) и требовать подтверждения.
- **Обработка ошибок**: Реализовать механизм повторных попыток и логирования для отладки.

### Этап 6: Расширение и кастомизация
- **Добавление новых навыков**: Реализовать инструменты для работы с браузером, отправки сообщений в мессенджеры и т.д. Благодаря модульной архитектуре, каждый новый навык — это просто новая Python-функция.
- **Горячие клавиши**: Настроить глобальные горячие клавиши для активации ассистента без использования кодового слова.
